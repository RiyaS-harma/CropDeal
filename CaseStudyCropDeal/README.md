# CropDeal - Farmer-Dealer Direct Trading Platform\n\nA microservices-based platform connecting farmers directly with dealers for crop trading, eliminating intermediaries and reducing costs.\n\n## Features\n\n### For Farmers\n- Register/Login with JWT authentication\n- Create and manage crop listings\n- View and manage orders\n- Receive payments directly\n- Generate receipts\n\n### For Dealers\n- Register/Login with JWT authentication\n- Browse available crops\n- Place orders\n- Make payments\n- Generate invoices\n\n### For Admins\n- User management (farmers/dealers)\n- Generate reports\n- Monitor platform activity\n\n## Architecture Patterns Implemented\n\n1. **Microservices Architecture** - Modular service design\n2. **Service Discovery** - Consul integration\n3. **Externalized Configuration** - Configuration service\n4. **CQRS Pattern** - Command Query Responsibility Segregation\n5. **Event Sourcing** - Payment transaction events\n6. **JWT Authentication** - Secure token-based auth\n\n## Setup Instructions\n\n### Prerequisites\n- .NET 9.0 SDK\n- SQL Server LocalDB\n- Consul (optional, for service discovery)\n\n### Installation\n\n1. **Clone and restore packages:**\n```bash\ndotnet restore\n```\n\n2. **Update database:**\n```bash\ndotnet ef database update\n```\n\n3. **Run the application:**\n```bash\ndotnet run\n```\n\n4. **Access Swagger UI:**\n   - Navigate to `https://localhost:5001/swagger`\n\n## API Endpoints\n\n### Authentication\n- `POST /api/auth/register` - Register new user\n- `POST /api/auth/login` - Login user\n\n### Crops (Farmers)\n- `GET /api/crops` - Get all available crops\n- `POST /api/crops` - Create new crop listing\n- `PUT /api/crops/{id}` - Update crop listing\n- `GET /api/crops/{id}` - Get crop details\n\n### Orders (Dealers)\n- `POST /api/orders` - Create new order\n- `GET /api/orders/{id}` - Get order details\n- `PUT /api/orders/{id}/confirm` - Confirm order (Farmer)\n- `PUT /api/orders/{id}/complete` - Complete order (Dealer)\n\n### Payment\n- `POST /api/payment/process` - Process payment\n\n### Admin\n- `GET /api/admin/farmers` - Get all farmers\n- `GET /api/admin/dealers` - Get all dealers\n- `PUT /api/admin/users/{id}/toggle-status` - Toggle user status\n- `GET /api/admin/reports/orders` - Get order reports\n- `GET /api/admin/reports/summary` - Get summary report\n\n## Configuration\n\nUpdate `appsettings.json` with your settings:\n\n```json\n{\n  \"ConnectionStrings\": {\n    \"DefaultConnection\": \"Your SQL Server connection string\"\n  },\n  \"Jwt\": {\n    \"Key\": \"your-secret-key-at-least-32-characters\",\n    \"Issuer\": \"CropDealApp\",\n    \"Audience\": \"CropDealUsers\"\n  },\n  \"Consul\": {\n    \"Host\": \"localhost\",\n    \"Port\": 8500\n  }\n}\n```\n\n## User Types\n\n1. **Farmer** (UserType = 1)\n   - Can create crop listings\n   - Can confirm orders\n   - Can view receipts\n\n2. **Dealer** (UserType = 2)\n   - Can browse crops\n   - Can place orders\n   - Can make payments\n\n3. **Admin** (UserType = 3)\n   - Can manage users\n   - Can generate reports\n   - Can view platform analytics\n\n## Sample API Usage\n\n### Register a Farmer\n```json\nPOST /api/auth/register\n{\n  \"email\": \"farmer@example.com\",\n  \"password\": \"Password123!\",\n  \"firstName\": \"John\",\n  \"lastName\": \"Farmer\",\n  \"userType\": 1,\n  \"address\": \"Farm Address\"\n}\n```\n\n### Create Crop Listing\n```json\nPOST /api/crops\nAuthorization: Bearer {jwt-token}\n{\n  \"cropType\": \"Vegetable\",\n  \"cropName\": \"Tomato\",\n  \"quantity\": 100,\n  \"unit\": \"kg\",\n  \"pricePerUnit\": 50,\n  \"location\": \"Farm Location\",\n  \"description\": \"Fresh organic tomatoes\"\n}\n```\n\n### Place Order (Dealer)\n```json\nPOST /api/orders?cropId=1&quantity=50\nAuthorization: Bearer {jwt-token}\n```\n\n## Technologies Used\n\n- **Backend**: ASP.NET Core 9.0\n- **Database**: Entity Framework Core with SQL Server\n- **Authentication**: JWT Bearer tokens\n- **Service Discovery**: Consul\n- **Documentation**: Swagger/OpenAPI\n- **Patterns**: CQRS, Event Sourcing, Microservices\n\n## Next Steps\n\n1.
